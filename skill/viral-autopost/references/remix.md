# 仿写方法

输入是拆解记录和 config/profile.md。先确认读者遇到什么问题、本次能带走什么、有哪些用户确认的事实。
按原结构填入用户自己的材料。素材不足就缩小主题或问用户，不能把原作者的数字、客户、成绩、履历换个名字拿来用。

六类钩子都可借逻辑：结果后解释、真实数字形成对比、前后变化、明确观点、注明来源的权威判断、具体痛点带出问题。选与用户素材匹配的一类，不为凑类型编数字。
开头仍是话题+钩子+可信度。跟随节拍推进，每一步增加信息，不重复换说法。

- X：简体，短句，普通账号控制在 280 加权字符；中文通常每字权重为 2，复合 emoji 为 2，链接按 23 计。premium 配置为 true 才跳过本地上限。
- Threads：繁体、台湾常用词（例如「資訊」「軟體」「影片」），≤500 字。先改语气再检查繁简，不只是机械转换。
- 默认正文无链接，来源放 source 和拆解记录。
- 结尾可留下具体思考，不强加关注、点赞或销售话术。

交付前对照原文检查：句子是否照搬、数字是否属于用户、经历是否可核对、观点是否夸大、是否泄露信息。把无依据的内容删除。
同时展示两个平台版本，用户选定和修改后等明确发布指令。
